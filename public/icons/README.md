# Ícones do PWA e das lojas

Arquivos esperados (gerados a partir do logotipo oficial da NGS Transportes):

| arquivo | uso |
|---|---|
| `public/logo.png` | favicon (`index.html`), 48×48 ou maior |
| `public/icons/icon-192.png` | PWA (Android) |
| `public/icons/icon-512.png` | PWA / splash |
| `public/icons/icon-maskable-512.png` | ícone adaptativo Android (logo dentro da área segura de 80%) |

Enquanto não existirem, o navegador só não mostra o ícone (não quebra o app nem o build).
