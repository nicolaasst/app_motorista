# Imagens da marca (NGS Transportes)

Coloque aqui os arquivos originais com **exatamente** estes nomes. O app passa a
usá-los automaticamente no próximo build (`src/lib/brandAssets.js`); enquanto um
arquivo não existir, o app usa a imagem atual.

| arquivo | onde aparece | tamanho sugerido |
|---|---|---|
| `icone.png` | cabeçalho do app (monograma), favicon | 512×512, fundo sólido |
| `logo-full.png` | logotipo completo (reservado; hoje nenhuma tela usa) | altura ≥ 256 px, fundo transparente |
| `mascote-triangulo-apontando.png` | Home sem rota | ~512 px, fundo transparente |
| `mascote-circulo-pensando.png` | Recibos / Notificações vazios | ~512 px, fundo transparente |
| `mascote-quadrado-cambalhota.png` | Conclusão de rota | ~512 px, fundo transparente |
| `mascote-arredondado-acenando.png` | Conclusão de rota | ~512 px, fundo transparente |

Ícones do PWA/lojas (`public/icons/icon-192.png`, `icon-512.png`,
`icon-maskable-512.png`) e `public/logo.png` (favicon): ver `public/icons/README.md`.
